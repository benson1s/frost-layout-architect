# Build the Momentum UI mockup

## Scope
- Replace the blank page with a responsive, UI-only mockup using the selected frosted-glass direction.
- Build login, home, activities and details, calendar, lessons, social profiles/feed, messages overlay, and settings.
- Use Chase and replaceable mock content throughout; use photo icons instead of photographs.
- Add the requested mock interactions and errors, without accounts, saved credentials, or a database.

## Interaction details
- Sign in and sign up enter the home screen.
- Habits toggle complete, filters narrow activities, activity posting validates required fields, and RSVP checks schedule conflicts.
- Lessons unlock sequentially and require a 30-word goal.
- Messages open above the current page; settings and social subviews are navigable.

## Technical details
- Keep the experience in the existing TanStack Start home route as an interactive prototype.
- Extend the global semantic token system for the frosted-glass palette and typography.
- Use existing interface controls and Lucide icons, with no image assets or generation.
- Verify the live preview at desktop and mobile sizes.
